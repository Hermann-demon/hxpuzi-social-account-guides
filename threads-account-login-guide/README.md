## 首登验收清单（到手当天完成）

![Threads 首登验收清单示意](images/gen-acceptance-checklist.jpg)

### 1. 下单前核对规格
- 看清是新号、语言名字款、地区显示款还是老脆；地区款看清「未显示归属地不换」这一条。
- IG 老号商品页写明：账号、密码、2FA 都正确但因网络环境无法登录的、登录时弹手机验证的、当天及之后被封的，都不在售后范围。介意就先买 1 个试。

### 2. 拆分并保存交付字段
- 常见格式：`用户名 | 密码 | 2FA密钥`，老号多一个 `邮箱`（以所购规格为准）。
- 交付原文和订单号存进密码管理器；截图时遮住密码和 2FA 密钥。

### 3. 准备登录环境与验证器
- 用稳定、干净的网络和设备；首登期间不要来回切换网络，一次只登录一个账号。
- 把 2FA 密钥导入自己的验证器，开启手机**自动日期与时间**（见 [2FA密钥登录教程](../2fa-key-login-guide/)）。商品页提到的第三方验证码网站不是官方要求，密钥不要贴到不明网站。

### 4. 在 Threads App 首次登录
- 打开官方 Threads App（地区款商品页建议在 Threads 上首登），输入用户名和密码。
- 要求双重验证时，填验证器**当前**生成的 6 位码；默认要短信时点「尝试其他方式」选身份验证应用。

### 5. 逐项验收并留证
| 验收项 | 怎么核对 | 留什么证据 |
| --- | --- | --- |
| 用户名 | 登录后的 Threads 用户名与交付一致 | 资料页截图（带时间） |
| 资料归属地（地区款） | 资料页 ⋯ →「关于此个人资料」，看所在地是否显示、是否与订单一致 | 从资料页进入该页的连续录屏 |
| IG 关联 | Threads 资料能跳到对应 IG 资料，IG 也能正常打开 | IG 资料页截图 |
| 2FA | 验证器生成的码能通过验证 | 通过后的页面截图（遮住密钥） |
| 账号状态 | 首页能刷新、能浏览，无停用提示 | 首页截图与时间 |

归属地显示但与订单不符，是地区款写明的可换情况；**没显示**只能记为未知，按商品页不换，也不要为了「催出」归属地去频繁切换网络或设备。更多地区号首登要点见官网 [Instagram地区号首登清单](https://hxpuzi.com/article/instagram-region-account-first-login-verification-guide/?utm_source=github)。

### 6. 验收通过后再安全接管
1. 先正常浏览、使用一段时间再改密码（IG 商品页提醒：新设备上**立即**改密码有封禁风险）。
2. 修改 IG 密码；无邮箱的规格，在 IG 账号中心绑定**你自己的**邮箱（商品页写明「邮箱可自绑」）。
3. 在账号中心重置 2FA，扫描**新**密钥，让旧密钥作废；离线保存备用码。
4. 检查登录活动，退出不认识的设备。
5. **一次只改一项**，每改完确认 Threads 和 IG 都还能正常登录，再做下一项。

## 首登失败排查表

| 现象 | 常见原因 | 怎么处理 |
| --- | --- | --- |
| 提示密码错误 | 字段拆错、复制多了空格或全角符号 | 从交付原文重新复制；仍错误就停止重试，留证找售后（地区款写明密码错误可换） |
| 2FA 验证码无效 | 手机时间不同步、密钥带空格、码刚好过期 | 开启自动时间，去掉密钥空格，等新码出现再填 |
| 页面报错 / 一直转圈 | 网络不稳定或公共网络被限制 | 换回稳定的网络后再试**一次**，不要连续重试 |
| 要求手机号或真人验证 | 新环境登录触发平台安全检查 | 停止操作、不要反复提交；英文名 / 日本款写明首登出现真人验证可换，IG 老号写明弹手机验证不售后——以所购规格为准 |
| 资料页没有所在地 | 该账号还未开启归属地字段 | 记为未知，不要切换网络去「刷」；按地区款条款不提供更换 |

## 常见问题

**Q1：Threads 能不能单独登录，不管 IG？**  
IG+Threads 商品用的是同一套 IG 凭据，Threads 资料挂在 IG 账号下。IG 被限制或改密，Threads 也会受影响，所以安全接管按 IG 来做。

**Q2：资料显示日本，是不是就会推给日本用户？**  
不是。归属地只是资料页的公开字段，不代表流量、受众或功能；也不保证以后一直不变。

**Q3：没显示归属地能换吗？**  
地区款商品页写明未开启归属地不提供更换（卖家称通常数日内会自动显示，但没有固定时间）。如果归属地是硬条件，下单前先确认能否接受这一条。

**Q4：名字是日文 / 繁中，算地区号吗？**  
不算。名字语言只是资料文字，地区承诺只看标题里写明「位置显示 XX」的规格。

**Q5：脆账号买新号还是老脆？**  
先走通流程选新号或 ¥5.04 手工注册款；想要已开通较久的 Threads 资料再看老脆。无论哪种，都先少量测试。
